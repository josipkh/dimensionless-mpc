# Tire plotting and model fitting
This folder contains a `.TIR` file taken from [IPG CarMaker](https://www.ipg-automotive.com/solutions/product-portfolio/carmaker). The scripts can be used to plot various curves and fit a linear tire model to the given Magic Formula (5.2) model.

In order to run the scripts, please install the [MFeval toolbox](https://www.mathworks.com/matlabcentral/fileexchange/63618-mfeval).
